# FOSS NSAS / Rapitec DA

The runtime reader supports the observed 700/1050/1700/4200-point NSAS geometries
and optional same-basename CN references. Only the original Beer Analyzer signature
is labelled absorbance; other signal semantics remain unknown.

| File | Source | License | Purpose |
|---|---|---|---|
| `synthetic.da` | Generated by `generate.py` | CC0-1.0 | Three independent synthetic spectra; repeated IDs and record numbers, leap-day timestamps, three transducer values and opaque header/trailer preservation. |
| `synthetic.spc` | Generated by `generate.py` | CC0-1.0 | The same arrays in standard Galactic SPC; independent full-array reference comparison with the MIT `spc-spectra` reader. |
| `references700.da`, `references700.cn` | Generated by `generate.py` | CC0-1.0 | Three 700-point spectra, two invented targets with valid zero values, NUL-padded IDs and varying model codes. |
| `variant1700.da`, `variant4200.da` | Generated by `generate.py` | CC0-1.0 | Two spectra each, 0.5 nm axes and different alignment padding; unknown signal semantics. |
| `generate.py` | Written for this repository | CC0-1.0 | Reproducible generation using only Python's standard library; no private measurements. |

The supplied `0LC1B44.DA` / `.SPC` pair is local-only in
`samples_local/foss_nsas_da/` because no redistribution license was supplied.
It is never bundled in the demo, source distribution or committed fixtures.
Two more private DA files (`0LC1B70.DA`, `0LC1B83.DA`) extend the checked corpus
to 191 spectra. The three supplied manuals and their local OCR stay in
`samples_local/foss_nsas_da/documentation_20261118/`. No additional private
measurements or copyrighted scans are added to these public fixtures.
See `docs/formats/foss-nsas-da.md` for the byte layout, evidence and limitations,
and `docs/formats/foss-nsas-workflow.md` for the page-cited workflow analysis.

The 30 DA / 28 CN vendor examples recovered from the official Vision installer
are proprietary and stay in the ignored local research corpus. Public fixtures
contain invented values only. Multi-target slot tests exercise the inspected
layout, not a recovered multi-target vendor example.
