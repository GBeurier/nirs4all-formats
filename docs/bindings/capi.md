# C ABI

`nirs4all-formats-capi` is the C ABI over the Rust registry and writers. The
[Java](java.md), [C#](csharp.md) and [Julia](julia.md) bindings call it; any
language with a C foreign-function interface can do the same. Records cross
the boundary as UTF-8 JSON, the same record JSON that `nirs4all-formats
read-json`, Python and WebAssembly produce (see [Data model](../DATA_MODEL.md)).
Parsing and writing stay in Rust.

The C ABI version (`n4fmt_abi_version`) is independent of the library version.
It is **0.2.0**: 0.1.0 symbols are unchanged, the read, export and convert
entry points below are new.

## Functions

All symbols are declared in `crates/nirs4all-formats-capi/include/nirs4all_formats.h`,
generated by cbindgen and committed.

| Function | Result JSON |
|---|---|
| `char *n4fmt_abi_version(void)` | C ABI version string (not JSON). |
| `char *n4fmt_library_version(void)` | Library version string (not JSON). |
| `void n4fmt_string_free(char *ptr)` | Frees any string returned by this ABI. |
| `bool n4fmt_core_is_available(void)` | Always true once the library is loaded. |
| `n4fmt_reader_catalog(out_json, out_error)` | `[{"reader": "nirs4all_formats::readers::jcamp"}, ...]` |
| `n4fmt_probe_path(path, out_json, out_error)` | `[{"format", "reader", "confidence", "reason"}]`, most confident first. |
| `n4fmt_probe_bytes(name, bytes, len, out_json, out_error)` | Same, for in-memory content; `name` drives extension-aware sniffers. |
| `n4fmt_open_path(path, options_json, out_json, out_error)` | Array of records. Companion files of sidecar formats are read next to `path`. |
| `n4fmt_open_bytes(name, bytes, len, options_json, out_json, out_error)` | Array of records. Formats that need a companion file fail with `N4FMT_STATUS_UNSUPPORTED_SIDECAR`. |
| `n4fmt_export_targets(out_json, out_error)` | `{"formats": [...], "software": [...]}`, as `nirs4all-formats targets`. |
| `n4fmt_write_records(records_json, target, options_json, out_json, out_error)` | `{"format", "files": [{"name", "media_type", "size", "bytes_base64"}], "losses": [...]}`. Nothing is written to disk. |
| `n4fmt_convert_path(input_path, target, output_dir, options_json, out_json, out_error)` | Reads `input_path`, saves into the existing `output_dir` and returns `{"format", "files": [paths], "losses": [...]}`, as `nirs4all-formats convert`. |

Every fallible function returns `n4fmt_status_t` (`int32_t`) and has the shape
`f(inputs..., char **out_json, char **out_error)`. A later
`n4fmt_plan_conversion(records_json, target, options_json, out_json, out_error)`
would follow the same shape.

### Options

`options_json` may be `NULL`, empty or a JSON object. Unknown keys are refused
with `N4FMT_STATUS_INVALID_ARGUMENT`.

- Read options (`n4fmt_open_*`): `single_record` (bool, an image cube as one
  N-dimensional record), `rows` and `cols` (`[start, end]` half-open windows,
  `end` may be `null`) or `pixels` (`[[row, col], ...]`). Windows and pixels
  are exclusive.
- Write options (`n4fmt_write_records`, `n4fmt_convert_path`): `signal`,
  `base_name`, `extension`, `axis_tolerance`, `multi`, `delimiter` (`","`,
  `";"` or `"\t"`) and `zip`, as described in [Exports](../EXPORTS.md).
  `n4fmt_convert_path` also takes `overwrite` (default `false`: nothing is
  written when any produced file already exists).

`losses` entries are `{"code", "message", "count", "max_error"?}`.

## Errors

| Status | Value | Meaning |
|---|---|---|
| `N4FMT_STATUS_OK` | 0 | `*out_json` holds the result. |
| `N4FMT_STATUS_INVALID_ARGUMENT` | 1 | Null required pointer, non-UTF-8 string, invalid options or records JSON. |
| `N4FMT_STATUS_IO` | 2 | A file cannot be read or saved, or an output file already exists. |
| `N4FMT_STATUS_UNSUPPORTED_FORMAT` | 3 | No reader recognizes the input. |
| `N4FMT_STATUS_UNSUPPORTED_SIDECAR` | 4 | A companion file is needed and not available. |
| `N4FMT_STATUS_INVALID_DATA` | 5 | The input is recognized but cannot be decoded. |
| `N4FMT_STATUS_UNKNOWN_TARGET` | 6 | The target is neither an export format nor a software preset. |
| `N4FMT_STATUS_EXPORT_REFUSED` | 7 | The records or options cannot be represented in the target. |
| `N4FMT_STATUS_INTERNAL` | 99 | A panic was caught inside the library (a bug). |

On failure `*out_json` is `NULL` and, when `out_error` is not `NULL`,
`*out_error` holds a UTF-8 message. Panics never cross the boundary.

## Memory

- Input strings are NUL-terminated UTF-8 and are only borrowed during the call.
  `bytes` may be `NULL` when `len` is 0.
- Every returned `char *` (result, error message, version) is owned by the
  caller and released with `n4fmt_string_free` exactly once, never `free()`.
- `out_json` must not be `NULL`; both out-pointers are reset at entry.

## Numbers

JSON floats are written in their shortest round-trip form and parsed with
correct rounding, so records read, sent back to `n4fmt_write_records` and
exported keep their values bit for bit. Missing values are `null` in JSON and
NaN in the records. Large records (image cubes) produce large JSON strings.

## Build and link

```bash
cargo build -p nirs4all-formats-capi --release
# target/release/libnirs4all_formats_capi.{so,dylib}, nirs4all_formats_capi.dll, .a/.lib
```

The crate builds as a `cdylib`, `staticlib` and `rlib`. `build.rs` regenerates
the header with cbindgen (config: `cbindgen.toml`); CI checks the committed
header is up to date. Tagged releases attach per-OS archives
(`nirs4all-formats-capi-<target>.{tar.gz,zip}`) with the library, the header and
the licenses; see [Release](../RELEASE.md).

## Example

```c
#include <stdio.h>
#include "nirs4all_formats.h"

int main(void) {
    char *json = NULL, *error = NULL;
    if (n4fmt_open_path("spectrum.spc", NULL, &json, &error) != N4FMT_STATUS_OK) {
        fprintf(stderr, "%s\n", error);
        n4fmt_string_free(error);
        return 1;
    }
    char *output = NULL;
    n4fmt_status_t status = n4fmt_write_records(json, "jcamp-dx", "{\"base_name\": \"out\"}", &output, &error);
    n4fmt_string_free(json);
    if (status != N4FMT_STATUS_OK) { fprintf(stderr, "%s\n", error); n4fmt_string_free(error); return 1; }
    printf("%s\n", output);  /* {"format": "jcamp-dx", "files": [...], "losses": [...]} */
    n4fmt_string_free(output);
    return 0;
}
```

```bash
cc -I crates/nirs4all-formats-capi/include example.c \
   -L target/release -Wl,-rpath,target/release -lnirs4all_formats_capi -o example
```

`crates/nirs4all-formats-capi/tests/smoke.c` exercises every entry point and is
compiled and run by `cargo test -p nirs4all-formats-capi` on Unix.
